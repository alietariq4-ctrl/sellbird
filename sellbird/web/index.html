Help & Quick Start
What VeloReach does, how every stage connects, and how to run a live demo or campaign.


  

    
What is VeloReach?

    
VeloReach is an end-to-end AI sales and email marketing platform: it discovers businesses, crawls their websites for buying signals, extracts & verifies contacts, writes personalized A/B email sequences, stages everything in a safe human-review Outbox, tracks replies, and books meetings.

    
Powered by the universal AI Router (Gemini, DeepSeek, OpenRouter, Groq, OpenAI-compatible / Ollama, or Claude / Codex) with all data stored locally on your machine.

  


  

    
Getting started in 4 steps

    
1. Your Company: Describe your offer in plain language (or train from URL)
2. Discover: Pick "OSM Live Places" or "YC Startups Directory" ($0 free keyless) and search leads
3. Campaigns & Outbox: Build A/B sequences, preview rendered HTML, and approve sends
4. Settings: Connect Resend SMTP (for demos/testing) or Gmail/M365 OAuth (for full cold + reply inbox)

    
Today shows your live pipeline metrics and next recommended action at a glance.

Getting your API keys


    

      Instantly API key (legacy)
      

        
Instantly is the legacy sending option; Gmail or SMTP is recommended.

        
1. Sign up at instantly.ai (you need the Growth plan for API access)

        
2. Go to Settings > Integrations

        
3. Copy your API key

        
4. Paste it in the Settings tab here

      

    


    

      LinkedIn credentials (optional)
      

        
If you want VeloReach to find prospects on LinkedIn, enter your LinkedIn email and password. VeloReach uses a real browser to search LinkedIn like a human would, with random delays and rate limits to avoid detection.

        
If you skip this, VeloReach will find prospects through Google searches and company website scraping instead.

      

    


    

      Cloudflare Browser Rendering (optional)
      

        
This is only used during product training (when VeloReach crawls your website to learn about your product). It handles JavaScript-heavy websites that a basic crawler can't read.

        
1. Sign up at Cloudflare (paid Workers plan, ~$5/month)

        
2. Go to Workers & Pages > Browser Rendering

        
3. Create an API token with Browser Rendering Edit permissions

        
4. Enter your Account ID and API Token in the Settings tab

        
Without this, VeloReach uses a built-in crawler that works fine for most websites but can't render JavaScript.

      

    

  


  

    
Common issues


    

      "command not found: sellbird"
      
You need to activate the virtual environment first: source .venv/bin/activate

    


    

      Instantly API returns 401
      
Your API key is wrong, or you need the Growth plan (the free plan doesn't include API access). Double-check the key in Settings > Integrations in your Instantly dashboard.

    


    

      Claude headless mode fails
      
Make sure you've run claude login in your terminal and have an active Claude Max subscription. VeloReach uses your existing subscription, not a separate API key.

    


    

      Codex calls fail
      
With brain.provider: codex, set brain.model to an available model ID, including Luna, Sol, or Terra (for example gpt-6.1-sol), or leave it blank to select a listed model. VeloReach runs these models without tools; gpt-5.5 also remains supported when present in your account's catalog. Run codex login and choose "Sign in with ChatGPT" (API-key logins are refused). VeloReach never renews your Codex login: if the log says it has expired or is due for renewal, use Codex once or run codex login. VeloReach needs Codex CLI 0.159.3 on macOS or Linux (Codex isn't supported on Windows; use Claude there) and refuses other versions. While Codex can't be used, VeloReach pauses (Today shows "Codex is paused" and why), leaves replies and queued emails untouched, and resumes once it's fixed; sellbird status --check checks on demand. If the log says isolation could not be verified, a Codex config layer is forcing a tool, hook, MCP server or custom endpoint back on — VeloReach refuses to send prompts until it is removed. VeloReach never falls back to Claude on its own.

    


    

      VeloReach isn't finding prospects
      
Check that your ICP (ideal customer profile) in sellbird.yaml has realistic titles, industries, and geography. If LinkedIn is set up, check that the credentials are correct. Check the Activity tab to see what VeloReach has been trying to do.
